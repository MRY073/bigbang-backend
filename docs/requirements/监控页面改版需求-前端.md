# 监控页面改版需求文档（前端开发）

## 一、需求概述

对三个监控页面（成品链接监控、潜力链接监控、自然流商品监控）进行改版，主要变更如下：
1. 隐藏原有的日均指标和波动指标展示
2. 新增折线图展示，支持5种指标的时间序列可视化
3. 新增【分析】和【改善方案】输入框，支持保存和读取

## 二、涉及页面

1. **成品链接监控页面**
2. **潜力链接监控页面**
3. **自然流商品监控页面**

三个页面的改版需求**完全相同**，可以复用同一套组件。

## 三、UI变更详情

### 3.1 移除的UI元素

以下UI元素需要**完全移除**，不再显示：

1. **日均访客**指标展示
   - 包括30日、15日、7日、3日、1日的日均访客数

2. **访客数短期波动相对长期基准(60)指标**展示
   - 包括波动方向、强度、等级等信息

3. **日均广告花费**指标展示
   - 包括30日、15日、7日、3日、1日的日均广告花费

4. **广告花费短期波动相对长期基准(60)指标**展示
   - 包括波动方向、强度、等级等信息

5. **日均销售额**指标展示
   - 包括30日、15日、7日、3日、1日的日均销售额

6. **销售额短期波动相对长期基准(60)指标**展示
   - 包括波动方向、强度、等级等信息

### 3.2 新增的UI元素

#### 3.2.1 折线图组件

**位置**: 每个商品卡片中，替换原有的指标展示区域

**功能要求**:

1. **图表类型**: 折线图（Line Chart）
2. **数据指标**: 支持显示5种指标，在同一图表内展示
   - 访客数（Visitors）
   - 加购率（Cart Rate，百分比显示，如15%）
   - 转化率（Conversion Rate，百分比显示，如5%）
   - 订单量/买家数（Order Count / Buyer Count，可切换显示）
   - GMV（Gross Merchandise Value，货币格式显示）

3. **多选框控制**: 
   - 在图表上方或侧边提供多选框（Checkbox）组件
   - 用户可以选择显示/隐藏某条折线
   - 默认全部选中（显示所有5条折线）
   - 多选框标签：
     - ☑ 访客数
     - ☑ 加购率
     - ☑ 转化率
     - ☑ 订单量/买家数（显示时，可以在"订单量"和"买家数"之间切换，或同时显示两条线）
     - ☑ GMV

4. **横坐标（X轴）**: 
   - 显示日期
   - 支持日期范围选择器（Date Range Picker）
   - 默认显示最近30天数据
   - 日期范围可调节（建议限制在1-365天之间）

5. **纵坐标（Y轴）**: 
   - 每种指标有各自的标准（单位）
   - 访客数：整数，单位"人"
   - 加购率：百分比，单位"%"
   - 转化率：百分比，单位"%"
   - 订单量/买家数：整数，单位"个"/"人"
   - GMV：货币，单位"THB"（泰铢）
   - **重要**: 纵坐标需要自适应数据范围，尽量占满图表高度，避免数据集中在底部

6. **图表交互**:
   - 支持鼠标悬停显示具体数值
   - 支持图例点击显示/隐藏折线
   - 支持缩放（可选）
   - 支持数据点标记（可选）

7. **数据加载状态**:
   - 显示加载中状态（Loading）
   - 显示无数据状态（Empty State）
   - 显示错误状态（Error State）

**技术实现建议**:
- 推荐使用 ECharts、Chart.js、Recharts 等图表库
- 如果使用 ECharts，可以使用 `yAxis` 的多个配置来支持不同单位
- 或者使用双Y轴（左侧Y轴和右侧Y轴）来区分不同单位的指标

#### 3.2.2 分析输入框

**位置**: 每个商品卡片中，折线图下方

**功能要求**:

1. **组件类型**: Textarea（多行文本输入框）
2. **标签**: "分析"
3. **占位符**: "请输入分析内容..."
4. **字数限制**: 最多10000字
5. **字数统计**: 显示当前字数/最大字数（如：1250/10000）
6. **自动保存**: 
   - 建议使用防抖（Debounce）机制，用户停止输入后自动保存
   - 或提供"保存"按钮手动保存
   - 保存成功后显示提示信息
7. **数据绑定**: 与后端接口同步，支持读取已保存的内容

#### 3.2.3 改善方案输入框

**位置**: 每个商品卡片中，分析输入框下方

**功能要求**:

1. **组件类型**: Textarea（多行文本输入框）
2. **标签**: "改善方案"
3. **占位符**: "请输入改善方案..."
4. **字数限制**: 最多10000字
5. **字数统计**: 显示当前字数/最大字数（如：800/10000）
6. **自动保存**: 同分析输入框
7. **数据绑定**: 与后端接口同步，支持读取已保存的内容

## 四、接口调用

### 4.1 列表接口变更

**接口地址**: 
- 成品链接监控: `GET /api/finished/link/monitor/list`
- 潜力链接监控: `GET /api/potential/link/monitor/list`
- 自然流商品监控: `GET /api/natural/stage/monitor/list`

**响应数据变更**:
- 不再包含 `visitorsAvg`、`visitorsVolatilityBaseline`、`adCostAvg`、`adCostVolatilityBaseline`、`salesAvg`、`salesVolatilityBaseline` 字段
- 新增 `analysis` 和 `improvementPlan` 字段（可能为 `null`）

**响应示例**:
```json
{
  "success": true,
  "message": "查询成功",
  "data": [
    {
      "id": "12345",
      "name": "商品名称",
      "image": "https://example.com/image.jpg",
      "warningLevel": "轻微",
      "warningMessages": [],
      "analysis": "这是分析内容...",
      "improvementPlan": "这是改善方案...",
      "custom_category_1": "分类1",
      ...
    }
  ]
}
```

### 4.2 新增折线图数据接口

**接口地址**:
- 成品链接监控: `GET /api/finished/link/monitor/chart`
- 潜力链接监控: `GET /api/potential/link/monitor/chart`
- 自然流商品监控: `GET /api/natural/stage/monitor/chart`

**请求参数**:
- `shopID`: 店铺ID
- `shopName`: 店铺名称
- `productID`: 商品ID
- `startDate`: 开始日期（YYYY-MM-DD格式）
- `endDate`: 结束日期（YYYY-MM-DD格式）

**响应示例**:
```json
{
  "success": true,
  "message": "查询成功",
  "data": {
    "dates": ["2024-01-01", "2024-01-02", "2024-01-03", ...],
    "visitors": [100, 120, 95, ...],
    "cartRate": [0.15, 0.18, 0.12, ...],
    "conversionRate": [0.05, 0.06, 0.04, ...],
    "orderCount": [5, 7, 4, ...],
    "buyerCount": [4, 6, 3, ...],
    "gmv": [500.00, 700.00, 400.00, ...]
  }
}
```

**调用时机**:
- 当用户选择商品或改变日期范围时调用
- 需要显示加载状态

### 4.3 新增保存分析接口

**接口地址**:
- 成品链接监控: `POST /api/finished/link/monitor/save-analysis`
- 潜力链接监控: `POST /api/potential/link/monitor/save-analysis`
- 自然流商品监控: `POST /api/natural/stage/monitor/save-analysis`

**请求参数** (Body, JSON):
```json
{
  "shopID": "店铺ID",
  "shopName": "店铺名称",
  "productID": "商品ID",
  "analysis": "分析内容（可选）",
  "improvementPlan": "改善方案（可选）"
}
```

**响应示例**:
```json
{
  "success": true,
  "message": "保存成功"
}
```

**调用时机**:
- 用户输入后，使用防抖机制自动保存（建议延迟500ms-1000ms）
- 或用户点击"保存"按钮时手动保存

## 五、组件设计建议

### 5.1 商品卡片组件结构

```
ProductCard
├── ProductHeader (商品信息：图片、名称、分类等)
├── WarningInfo (预警信息，保留)
├── ChartSection
│   ├── ChartControls (日期范围选择器 + 多选框)
│   └── LineChart (折线图)
├── AnalysisSection
│   ├── AnalysisTextarea (分析输入框)
│   └── CharacterCount (字数统计)
└── ImprovementPlanSection
    ├── ImprovementPlanTextarea (改善方案输入框)
    └── CharacterCount (字数统计)
```

### 5.2 折线图组件设计

**Props**:
```typescript
interface LineChartProps {
  data: {
    dates: string[];
    visitors: (number | null)[];
    cartRate: (number | null)[];
    conversionRate: (number | null)[];
    orderCount: (number | null)[];
    buyerCount: (number | null)[];
    gmv: (number | null)[];
  };
  visibleSeries: {
    visitors: boolean;
    cartRate: boolean;
    conversionRate: boolean;
    orderCount: boolean;
    buyerCount: boolean;
    gmv: boolean;
  };
  loading?: boolean;
  error?: string;
}
```

**功能**:
- 根据 `visibleSeries` 控制哪些折线显示
- 处理 `null` 值（不显示数据点或显示为断线）
- 自适应Y轴范围
- 格式化数值显示（百分比、货币等）

### 5.3 日期范围选择器

**功能**:
- 支持选择开始日期和结束日期
- 限制日期范围（建议1-365天）
- 默认选择最近30天
- 选择后自动刷新图表数据

### 5.4 多选框组件

**功能**:
- 控制5种指标的显示/隐藏
- 默认全部选中
- 至少保留一条折线显示（不能全部取消）

## 六、数据处理

### 6.1 数据格式化

1. **访客数**: 直接显示整数，如 `100`
2. **加购率**: 转换为百分比显示，如 `0.15` → `15%`
3. **转化率**: 转换为百分比显示，如 `0.05` → `5%`
4. **订单量/买家数**: 直接显示整数，如 `5`
5. **GMV**: 格式化为货币显示，如 `500.00` → `500.00 THB` 或 `฿500.00`

### 6.2 缺失数据处理

- 如果某天的数据为 `null`，在图表中不显示该数据点
- 或显示为断线（前后数据点不连接）

### 6.3 Y轴范围计算

- 对于每条折线，计算其数据的最小值和最大值
- 根据最小值和最大值设置Y轴范围
- 可以添加适当的边距（如上下各留10%的空间）

## 七、用户体验优化

### 7.1 加载状态

- 图表加载时显示骨架屏（Skeleton）或加载动画
- 输入框保存时显示保存中状态

### 7.2 错误处理

- 接口调用失败时显示错误提示
- 提供重试按钮
- 字数超限时显示错误提示

### 7.3 性能优化

- 使用防抖机制减少接口调用
- 图表数据量大时考虑数据采样或分页加载
- 使用虚拟滚动（如果商品列表很长）

### 7.4 响应式设计

- 确保在不同屏幕尺寸下正常显示
- 移动端可以考虑折叠图表或简化交互

## 九、开发优先级

1. **P0（必须）**: 
   - 移除旧指标展示
   - 实现折线图基础功能（显示5种指标）
   - 实现分析/改善方案输入框基础功能（保存和读取）

2. **P1（重要）**:
   - 实现多选框控制折线显示
   - 实现日期范围选择器
   - 实现Y轴自适应
   - 实现防抖保存

3. **P2（优化）**:
   - 优化图表交互（悬停、缩放等）
   - 优化加载状态和错误处理
   - 优化响应式设计

## 十、注意事项

1. **向后兼容**: 本次改版不兼容旧版本，需要确保前后端同时发布
2. **数据迁移**: 如果旧数据中有分析/改善方案内容，需要确认是否需要迁移
3. **性能考虑**: 如果商品数量很多，考虑是否需要分页或虚拟滚动
4. **图表库选择**: 根据项目现有技术栈选择合适的图表库，避免引入过多依赖
