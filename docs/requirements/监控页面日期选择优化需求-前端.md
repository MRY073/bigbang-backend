# 监控页面日期选择优化需求文档（前端开发）

## 一、需求概述

对三个监控页面（成品链接监控、潜力链接监控、自然流链接监控）进行日期选择功能优化，主要变更如下：
1. 删除页面最顶部的日期选择组件
2. 每个商品卡片内的日期范围选择器选择完成后，自动拉取对应时间段的数据

## 二、涉及页面

1. **成品链接监控页面**
2. **潜力链接监控页面**
3. **自然流链接监控页面**

三个页面的优化需求**完全相同**。

## 三、UI变更详情

### 3.1 移除的UI元素

**页面顶部的日期选择组件**
- 位置：页面最上方，用于选择查询日期
- 操作：完全移除该组件及其相关UI元素
- 影响：页面不再显示全局日期选择器

### 3.2 保留和优化的UI元素

**商品卡片内的日期范围选择器**
- 位置：每个商品卡片中，折线图上方（ChartControls区域）
- 功能：保留并优化该组件
- 优化要求：
  1. 日期范围选择完成后，自动触发折线图数据拉取
  2. 显示加载状态，提示用户数据正在加载
  3. 如果选择失败或数据为空，显示相应的错误或空状态提示

## 四、接口调用变更

### 4.1 列表接口调用变更

**接口地址**（保持不变）:
- 成品链接监控: `GET /api/finished/link/monitor/list`
- 潜力链接监控: `GET /api/potential/link/monitor/list`
- 自然流商品监控: `GET /api/natural/stage/monitor/list`

**请求参数变更**:
- **移除**: `date` 参数（不再需要）
- **保留**: `shopID`、`shopName`、`customCategory`（可选）

**变更前**:
```
GET /api/finished/link/monitor/list?shopID=xxx&shopName=xxx&date=2024-01-15
```

**变更后**:
```
GET /api/finished/link/monitor/list?shopID=xxx&shopName=xxx
```

**调用时机**:
- 页面初始化时调用（不再需要用户选择日期）
- 店铺切换时调用
- 分类筛选时调用（如果有）

### 4.2 折线图接口调用优化

**接口地址**（保持不变）:
- 成品链接监控: `GET /api/finished/link/monitor/chart`
- 潜力链接监控: `GET /api/potential/link/monitor/chart`
- 自然流商品监控: `GET /api/natural/stage/monitor/chart`

**请求参数**（保持不变）:
- `shopID`: 店铺ID
- `shopName`: 店铺名称
- `productID`: 商品ID
- `startDate`: 开始日期（YYYY-MM-DD格式）
- `endDate`: 结束日期（YYYY-MM-DD格式）

**调用时机变更**:
- **变更前**: 用户选择商品或改变日期范围时调用
- **变更后**: 
  1. 商品卡片展开时，使用默认日期范围（最近30天）自动调用
  2. **用户选择日期范围完成后，立即自动调用**（新增）
  3. 商品切换时调用

**自动调用逻辑**:
```typescript
// 伪代码示例
const handleDateRangeChange = (startDate: string, endDate: string) => {
  // 1. 显示加载状态
  setLoading(true);
  
  // 2. 立即调用折线图接口
  fetchChartData({
    shopID,
    shopName,
    productID,
    startDate,
    endDate
  }).then(data => {
    // 3. 更新图表数据
    updateChartData(data);
    setLoading(false);
  }).catch(error => {
    // 4. 显示错误提示
    showError(error);
    setLoading(false);
  });
};
```

## 五、用户体验优化

### 5.1 加载状态

**日期范围选择完成后**:
- 显示图表加载动画（Skeleton或Spinner）
- 可以显示提示文字："正在加载数据..."
- 禁用日期选择器，防止重复选择

**加载完成**:
- 隐藏加载动画
- 恢复日期选择器可用状态
- 更新图表数据

### 5.2 错误处理

**接口调用失败时**:
- 显示错误提示（Toast或Alert）
- 提供重试按钮
- 保持当前日期范围选择状态

**数据为空时**:
- 显示空状态提示："该时间段暂无数据"
- 图表显示空状态UI

### 5.3 防抖处理（可选）

如果日期范围选择器支持实时选择（如拖动选择），建议添加防抖处理：
- 延迟300-500ms后再调用接口
- 避免用户快速调整日期范围时频繁调用接口

### 5.4 默认日期范围

**建议默认值**:
- 默认选择最近30天
- 开始日期：30天前
- 结束日期：今天

**计算方式**:
```typescript
const today = new Date();
const thirtyDaysAgo = new Date();
thirtyDaysAgo.setDate(today.getDate() - 30);

const defaultStartDate = formatDate(thirtyDaysAgo); // YYYY-MM-DD
const defaultEndDate = formatDate(today); // YYYY-MM-DD
```

## 六、组件设计建议

### 6.1 商品卡片组件结构（更新）

```
ProductCard
├── ProductHeader (商品信息：图片、名称、分类等)
├── WarningInfo (预警信息，保留)
├── ChartSection
│   ├── ChartControls
│   │   ├── DateRangePicker (日期范围选择器，选择完成后自动调用接口)
│   │   └── CheckboxGroup (多选框，控制指标显示)
│   └── LineChart (折线图，显示加载状态)
├── AnalysisSection
│   ├── AnalysisTextarea (分析输入框)
│   └── CharacterCount (字数统计)
└── ImprovementPlanSection
    ├── ImprovementPlanTextarea (改善方案输入框)
    └── CharacterCount (字数统计)
```

### 6.2 日期范围选择器组件

**Props**:
```typescript
interface DateRangePickerProps {
  startDate: string; // YYYY-MM-DD
  endDate: string; // YYYY-MM-DD
  onChange: (startDate: string, endDate: string) => void; // 选择完成后回调
  loading?: boolean; // 是否正在加载数据
  disabled?: boolean; // 是否禁用
}
```

**功能要求**:
1. 支持选择开始日期和结束日期
2. 限制日期范围（建议1-365天）
3. 选择完成后立即触发 `onChange` 回调
4. 加载时显示禁用状态
5. 支持键盘操作（可选）

### 6.3 自动调用逻辑

**实现方式**:
```typescript
// React示例
const [dateRange, setDateRange] = useState({
  startDate: getDefaultStartDate(),
  endDate: getDefaultEndDate()
});

const [chartLoading, setChartLoading] = useState(false);

// 日期范围变化处理
const handleDateRangeChange = useCallback(async (startDate: string, endDate: string) => {
  // 更新日期范围
  setDateRange({ startDate, endDate });
  
  // 显示加载状态
  setChartLoading(true);
  
  try {
    // 调用折线图接口
    const data = await fetchChartData({
      shopID,
      shopName,
      productID,
      startDate,
      endDate
    });
    
    // 更新图表数据
    setChartData(data);
  } catch (error) {
    // 错误处理
    showError('数据加载失败，请重试');
  } finally {
    setChartLoading(false);
  }
}, [shopID, shopName, productID]);

// 组件挂载时自动调用一次
useEffect(() => {
  handleDateRangeChange(dateRange.startDate, dateRange.endDate);
}, []); // 仅在组件挂载时调用
```

## 八、开发优先级

1. **P0（必须）**: 
   - 移除页面顶部日期选择组件
   - 修改列表接口调用，移除 `date` 参数
   - 实现日期范围选择完成后自动调用折线图接口

2. **P1（重要）**:
   - 实现加载状态显示
   - 实现错误处理和重试功能
   - 实现默认日期范围（最近30天）

3. **P2（优化）**:
   - 添加防抖处理（如果需要）
   - 优化加载动画和用户体验
   - 添加键盘操作支持（可选）

## 九、注意事项

1. **向后兼容**: 
   - 本次变更需要后端同步更新，确保列表接口不再要求 `date` 参数
   - 需要与后端确认接口变更时间，确保前后端同时发布

2. **默认行为**:
   - 确认默认日期范围（建议最近30天）
   - 确认商品卡片展开时的默认行为

3. **性能考虑**:
   - 如果商品数量很多，考虑是否需要延迟加载折线图数据（仅在卡片展开时加载）
   - 考虑添加缓存机制，避免重复请求相同日期范围的数据

4. **用户体验**:
   - 确保加载状态清晰可见
   - 确保错误提示友好易懂
   - 确保日期选择器交互流畅
